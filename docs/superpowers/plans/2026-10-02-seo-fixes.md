# Corrections SEO — plan d'exécution

Source : audit SEO du 2026-10-02 (habitat-afrik.com vient de basculer sur la refonte). Exécution inline, une tâche = un commit, gate `pnpm format && pnpm lint && pnpm typecheck && pnpm test` avant chaque push.

## Décisions
- **Rendu serveur sans réécrire le design** : chaque page publique devient `page.tsx` (composant serveur : `generateMetadata`, JSON-LD, chargement des données via `lib/server/public/*`) qui rend le composant client existant (renommé `*Client.tsx`) avec `initialData`. Le client s'affiche directement avec ces données ; il garde son fetch au montage (le compteur de vues reste incrémenté par l'API, donc seulement pour les vrais navigateurs).
- **Logique partagée** : les requêtes des routes `/api/public/*` sont extraites dans `lib/server/public/*.ts` (une seule source pour l'API et le SSR).
- **Titres SEO générés** à partir des champs structurés (type, transaction, ville, chambres, prix), pas du titre brut saisi (majuscules, numéros de téléphone…). Le titre brut reste le H1.
- **Slug d'annonce** : `/annonces/<slug>-<id>` ; l'id (cuid, sans tiret) = dernier segment après `-`. Toute autre forme → 308 vers l'URL canonique.
- **Indexation** : pages privées en `X-Robots-Tag: noindex` (next.config headers) + `Disallow` dans robots.txt. Annonces « minces » (prix < 1 000, aucune photo) : `noindex` + hors sitemap.
- **Analytics** : GTM `GTM-56PZ4HQ`, GA4 `G-L9LX1ETMMJ` + `G-Z9K09T0TDY`, Pixels Meta `1141777894801586` + `706225327426885` (repris de l'ancien site). Fichiers de vérification Google + Facebook remis dans `frontend/public/`.
- **Images** : `next/image` (optimiseur Next servi depuis habitat-afrik.com) pour les photos d'annonces → plus de dépendance directe à `r2.dev` côté navigateur, tailles adaptées, lazy-loading.
- **Anciennes URL** : `detail-annonce.php?annonce=ID` (domaine principal + sous-domaines pays) → `/ancienne-annonce/ID` → 301 vers la fiche (lookup `legacyId`), sinon vers `/annonces`. Idem agents. Articles de blog : réimportés puis 301 un par un.
- **www → apex** : règle Apache dans `~/public_html/.htaccess` + canonical dans toutes les métadonnées.
